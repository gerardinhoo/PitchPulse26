# Client package

React + TypeScript + Vite frontend for **PitchPulse 26**.

For product context, architecture, and local setup of the full monorepo, use the root [README.md](../README.md) and [docs/](../docs/README.md).

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm test
npm run build
```

Set `VITE_API_URL` if the API is not at `http://localhost:5050/api`.
