## Guidelines

- Prefer lossless or compressed PNG/WebP under ~500KB each
- Do not capture emails, JWTs, `.env`, Neon URLs, or admin secrets
- Blur other users’ emails if they ever appear
- After adding files, update root README Screenshots section with relative markdown images
